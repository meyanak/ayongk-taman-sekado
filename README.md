# Meyanak

Prototype jejaring sosial modern dengan pengalaman penggunaan yang terinspirasi pola umum platform sosial besar, tetapi menggunakan identitas, nama, ikon, dan visual Meyanak sendiri.

## Fitur demo
- Beranda dengan stories, composer, feed postingan
- Like, komentar, bagikan
- Membuat postingan baru
- Pencarian postingan
- Navigasi Profil, Teman, Komunitas, Tersimpan, Kegiatan, Jelajah, Notifikasi
- Sidebar kontak dan komunitas
- Responsive desktop/tablet/mobile

## Menjalankan
Cukup buka `index.html` di browser modern. Tidak membutuhkan server untuk demo frontend.

## Pengembangan berikutnya
Sambungkan frontend ke backend untuk autentikasi, database, upload media, komentar real-time, sistem pertemanan, komunitas, notifikasi, moderasi, dan penyimpanan sesi.
